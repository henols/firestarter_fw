# Firestarter Firmware

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Buy me a coffee](https://img.shields.io/badge/Ko--fi-Buy%20me%20a%20coffee-FF5E5B?logo=ko-fi&logoColor=white)](https://ko-fi.com/E1E21I2WWW)

This repository holds the firmware of the Firestarter EPROM programmer. It runs on the Arduino
with the RURP shield. The `firestarter` command-line tool installs it on your board.

- **Start here:** the [Firestarter project page](https://github.com/henols/firestarter#readme).
- **Install and use it:** the [Firestarter wiki](https://github.com/henols/firestarter/wiki).

## Technical documents

- [DEVELOPMENT.md](DEVELOPMENT.md): the boards, and how to build, test and flash the firmware.
- [PROTOCOLS.md](PROTOCOLS.md): how the firmware writes, erases and identifies each chip family.
- [PINOUTS.md](PINOUTS.md): how the Arduino pins connect to the shield, and the control-register
  bits.
- [platform/py32f071/README.md](platform/py32f071/README.md): the PY32F071 port (beta only, no
  PCB exists).
